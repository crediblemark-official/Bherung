Kebijakan Privasi (Privacy Policy)

Terakhir diperbarui: 17 Agustus 2026

Selamat datang di Bherung POS, aplikasi kasir dan manajemen ritel toko kelontong yang dikembangkan oleh CredibleMark Official. Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, dan melindungi data pribadi Anda saat menggunakan aplikasi Bherung POS.

1. Data yang Dikumpulkan

Bherung POS menghormati privasi pengguna. Kami hanya mengumpulkan data yang diperlukan untuk menjalankan fungsionalitas kasir, yaitu:

  • Informasi Akun Google: Alamat email dan nama tampilan akun Google Anda untuk tujuan autentikasi dan pembuatan file database toko.
  • Data Operasional Toko: Daftar katalog produk, harga, stok, data riwayat transaksi kasir, dan catatan buku kasbon.

2. Penggunaan Google User Data (Google API Scopes)

Penggunaan Izin Google Drive & Sheets: Bherung POS menggunakan izin https://www.googleapis.com/auth/drive.file dan https://www.googleapis.com/auth/spreadsheets semata-mata untuk membuat, membaca, dan memperbarui spreadsheet database toko di akun Google Drive pribadi Anda sendiri.

Aplikasi kami mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use:

  • Kami TIDAK PERNAH membaca atau mengakses file lain di luar file spreadsheet yang dibuat oleh aplikasi Bherung POS.
  • Kami TIDAK MENJUAL atau membagikan data pengguna dan data transaksi toko kepada pihak ketiga, pengiklan, atau pihak eksternal lainnya.
  • Data Anda tidak digunakan untuk melatih model kecerdasan buatan (AI) umum.

3. Penyimpanan dan Keamanan Data

Seluruh data penjualan, keuntungan, dan transaksi toko disimpan secara langsung di akun Google Drive Anda sendiri dan cache penyimpanan lokal perangkat HP Anda. Anda memiliki kepemilikan dan kendali penuh atas data bisnis Anda.
